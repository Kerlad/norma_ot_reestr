# Соответствие требованиям 152-ФЗ, ПП РФ №1119 и Приказа ФСТЭК №21

**Проект:** Норма ОТ: Реестр обучения (ИСПДн — передача данных в реестр Минтруда)
**Версия:** 3.1.0
**Дата:** 22.05.2026
**Гриф:** ДСП (для служебного пользования)

## 1. Статус информационной системы

### 1.1. Назначение
Приложение «Норма ОТ: Реестр обучения» является **информационной системой персональных данных (ИСПДн)**, предназначенной для:
- Учёта и контроля обучения сотрудников по охране труда
- Формирования XML-файлов для передачи в реестр обученных лиц Минтруда РФ
- Отправки данных через API edu.rosmintrud.ru
- Хранения данных об обучении работников

### 1.2. Правовое основание обработки ПДн

Обработка персональных данных осуществляется **БЕЗ согласия субъекта** на основании:

| НПА | Основание |
|-----|-----------|
| 152-ФЗ ст.6 ч.2 п.1 | Обработка необходима для исполнения обязанностей, возложенных на оператора законодательством РФ |
| 152-ФЗ ст.6 ч.2 п.5 | Обработка необходима для исполнения трудового договора |
| ТК РФ ст.14, 86-90 | Обработка в целях охраны труда и обеспечения безопасности |
| Постановление №2464 пп. «е» п. 37 | Обязанность работодателя передавать сведения об обучении в Минтруд |

**Критическое замечание:** Приложение НЕ запрашивает и НЕ требует согласия субъекта ПДн. Любые ссылки на необходимость согласия в документации или коде являются ошибочными и подлежат исправлению.

### 1.3. Классификация ИСПДн

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| Категория ПДн | Категория 2 (иные ПДн, позволяющие идентифицировать субъекта) | ФИО + СНИЛС позволяют идентифицировать |
| Количество субъектов | до 100 000 | Технический лимит приложения |
| Тип угроз | Тип 3 (актуальные угрозы без специфических) | Десктоп-приложение, без WEB-сервера, без СУБД |
| **Уровень защищённости** | **УЗ-3** | Согласно ПП РФ №1119, п.14 |
| Рекомендуемый УЗ | УЗ-2 (для запаса) | В организациях с количеством работников >100 000 |

## 6. Дисклеймеры и ограничения

### 6.1. Что НЕ делает данное приложение

- **НЕ является сертифицированным СКЗИ** (сертификация ФСТЭК/ФСБ не проводилась)
- **НЕ использует ГОСТ-криптографию**
- **НЕ заменяет организационные меры** (политика ПДн, приказы, обучение)
- **НЕ гарантирует безопасность при скомпрометированной ОС**
- **НЕ обеспечивает WORM-хранение audit-лога**
- **НЕ имеет встроенного механизма обновлений**

### 6.2. Зависимость от ОС

Безопасность приложения критически зависит от:
- BitLocker (шифрование диска)
- Антивирус (Microsoft Defender или аналог)
- Windows Update (своевременные обновления)
- Учётная запись (надёжный пароль)
- Физический доступ (охраняемое помещение)
- Компрометация Windows-аккаунта = компрометация DPAPI = компрометация мастер-ключа

### 6.3. Остаточные риски

| Риск | Уровень | Комментарий |
|------|---------|-------------|
| Memory dump процесса | Средний | Мастер-ключ в памяти (global), не зануляется |
| Clipboard leakage | Средний | Нет auto-clear |
| Key storage без passphrase | Низкий | Только в PRODUCTION MODE |
| Backup ZIP (ZipCrypto) | Средний | PKWARE уязвим к known-plaintext |
| Audit log tampering | Средний | Нет верификации HMAC |
| 17/34 audit events не эмитируются | Высокий | Dead code в audit system |
| Plaintext кэш в encrypt cache | Средний | 2000 plaintext entries в памяти |
