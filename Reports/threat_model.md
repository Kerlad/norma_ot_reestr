## 1. Границы системы (System Boundary)

### 1.1. Входит в scope

| Компонент | Описание |
|-----------|----------|
| Приложение | main.py и все модули (.py) |
| SQLite БД | app_data.db с зашифрованными ПДн |
| Ключевая инфраструктура | master.key, master.key.json, passphrase_wrapped.key |
| Файлы конфигурации | api_key.json, org_settings.json, proxy_settings.json и др. |
| Логи | app.log, error.log, audit.log |
| Временные файлы | Директория secure_temp/ |
| Канал API | TLS-соединение с edu.rosmintrud.ru |

### 1.2. НЕ входит в scope

| Компонент | Причина |
|-----------|---------|
| Операционная система Windows 10/11 | Предполагается защищённая ОС |
| Сетевая инфраструктура | Локальная сеть, маршрутизаторы |
| Физический доступ к ПК | Организационная мера |
| BitLocker / шифрование диска | ОС-уровень |
| Антивирус | ОС-уровень |
| Другие приложения на ПК | Изолированная среда |

### 1.3. Предположения безопасности

1. ОС Windows 10/11 Professional (с BitLocker) — защищена от физического доступа
2. Учётная запись пользователя защищена паролем
3. Системное ПО обновляется (Windows Update)
4. Установлен и активен антивирус
5. Сетевое соединение защищено корпоративным firewall
6. Оператор обучен работе с ПДн
7. Мастер-ключ и passphrase хранятся отдельно от ПК (организационно)

## 6. Attack Surface

| Вектор | Описание | Защита |
|--------|----------|--------|
| Imported files (XLSX, XML) | Внешние файлы могут содержать вредоносные данные | defusedxml, ограничения размера |
| API responses (XML) | Ответы сервера парсятся | defusedxml |
| TLS network (MiTM) | Атака на TLS-соединение | TLS verify=True |
| Local file system | Прямой доступ к файлам БД/ключей | Полевое шифрование, DPAPI |
| Memory access (debugger) | Дамп памяти процесса | Нет кэша plaintext |
| Clipboard | Копирование ПДн | Не очищается автоматически |
| GUI скриншоты | Визуальная утечка | Нет защиты (clean desk policy) |
