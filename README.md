## Описание

Десктопное приложение, которое закрывает полный цикл работы специалиста по охране труда с реестром Минтруда:

**внесение данных → XML по схеме Минтруда → отправка в реестр (`edu.rosmintrud.ru`) → регистрационные номера → протоколы проверки знаний → сводка и план обучения.**

- Все данные хранятся **только на вашем компьютере** (`%APPDATA%\NormaOT`, в Linux — `~/.local/share/NormaOT`), ФИО и СНИЛС шифруются. Телеметрии нет, сеть используется только для обмена с реестром.
- Срок повторного обучения в сводке — **3 года для всех программ** (1–4 и 6–29): Правила обучения № 2464 в редакции постановления № 805, действует с 31.08.2026. Если отраслевые правила по охране труда устанавливают для программы В другую периодичность, её контролируют отдельно.
- Весь функционал бесплатный, исходный код открыт (MIT).

## Возможности

### Разделы программы

Навигация — боковое меню слева (раздел «Протоколы» вынесен в отдельную группу, внизу «Настройки и темы» и «Справка»).

| Раздел | Что делает |
|---|---|
| **Внесение данных** | Зона перетаскивания для `.xlsx` (до 10 МБ / 100 000 строк) и `.xml` (с проверкой по XSD), ход импорта с отменой, «Последняя загрузка», ручной ввод (СНИЛС форматируется как `XXX-XXX-XXX XX`, «Добавить и ещё»), шаблон XLSX, данные учебного центра и заказчика, схема XML |
| **Просмотр данных** | Таблица записей, редактирование («запись N из M», стрелки ←/→), удаление, «Подставить УЦ и заказчика», «Сформировать XML» и «Сформировать XML и перейти к передаче» (файл `ДДММГГГГ-ЧЧ-ММ.xml` в папку XML) |
| **Передача данных** | Отправка XML в реестр без подписи или с электронной подписью `.sig` (архив `.olot` для РОЛ); API-ключ; запрос регистрационных номеров по SetId или СНИЛС; история отправок со статусами |
| **Журнал проверки знаний** | Записи со статусом-значком, фильтры, «Получить номера из реестра», импорт файла-ответа по SetId без дублей, печать протоколов |
| **Сводка по сотрудникам** | Справочник работников и их программ, статусы «Не обучен / Просрочено / Обучен» значками, закреплённые столбцы, запрос из реестра по СНИЛС, «Импорт отчёта из реестра», план обучения, отчёт по обученным, «Текущая ситуация», импорт/экспорт XLSX |
| **Настройка протоколов** | Организация и состав комиссии, программы обучения, шаблон DOCX |
| **Быстрый протокол** | Протокол проверки знаний на одного работника с ручным вводом |

«Настройки и темы»: внешний вид, подключение к реестру (прокси), безопасность, блокировка сеанса, папка для XML, организации, «О программе».

### Несколько организаций

- Кнопка организации вверху бокового меню: сменить, добавить, удалить; при запуске выбор организации (с числом сотрудников).
- У каждой организации свои сотрудники, журнал, API-ключ и настройки протоколов; мастер-ключ, логи и тема общие.

### Работа в корпоративной сети

- Windows: транспорт WinHTTP (единые с Windows прокси и Kerberos/NTLM), запасные транспорты `urllib` и `requests` — при ошибке TLS программа сама пробует следующий. Linux: `requests` / `urllib`, прокси из переменных `https_proxy` / `http_proxy`.
- Автоопределение корпоративной среды (например, прокси РЖД), ручная настройка прокси.
- При SSL-инспекции прокси программа предлагает повторить отправку без проверки сертификата — только с подтверждением пользователя и записью в журнал аудита.

### Удобство

- Темы: «Норма» (по умолчанию), «Monokai тёмная», «Monokai светлая». Старые темы прежних версий заменяются на ближайшую.
- Сортировка щелчком по заголовку таблицы (по возрастанию, по убыванию, исходный порядок), ширина столбцов таблиц запоминается, размер и положение окна тоже.
- Справка по работе с программой — `F1` или «Справка» в боковом меню; справочник номеров программ обучения — в окне справки.
- Шрифты Rubik и Space Grotesk (SIL Open Font License 1.1) лежат в `resources/fonts/` вместе с текстами лицензий.

## Решение проблем

### «Ошибка поддержки безопасных каналов» / ошибка TLS при отправке или запросе

Windows не смогла установить защищённое соединение с `edu.rosmintrud.ru` (WinHTTP 12157). Чаще всего встречается на Windows 10.

1. **Обновите программу до 3.8.1 или новее.** Начиная с этой версии программа явно включает TLS 1.2/1.3, а при неудаче сама повторяет запрос через встроенный OpenSSL-транспорт.
2. Установите обновления Windows (старые сборки Windows 10 не поддерживают наборы шифров, которые требует сервер).
3. Проверьте дату и время на компьютере — при неверных часах сертификат сервера считается недействительным.
4. Если ошибка говорит о недоверенном центре сертификации, а в организации есть прокси с SSL-инспекцией — обратитесь в ИТ-службу или повторите отправку без проверки сертификата (программа предложит это сама; флажок «Проверять TLS-сертификат сервера» на вкладке «Передача данных»).

### Windows предупреждает о неизвестном издателе

Это ожидаемо для самоподписанного сертификата: нажмите «Подробнее → Выполнить в любом случае». Проверить подлинность файла можно по SHA-256 архива и отпечатку сертификата (см. [Скачать](#скачать)). Для организаций — [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md).

### Где лежат данные и логи

- Данные: `%APPDATA%\NormaOT` (до версии 3.6.0 — `%APPDATA%\Excel_to_XML`, переносятся автоматически). Linux: `~/.local/share/NormaOT`.
- Логи: `%APPDATA%\NormaOT\log` (Linux: `~/.local/share/NormaOT/log`), просмотр — «Инструменты → Просмотр логов». Полный ответ сервера при ошибке сохраняется в `log\error_response.txt`.
- Полное удаление — «Инструменты → Удалить все данные приложения».

Если проблема не решилась — напишите на [denis.krv@yandex.ru](mailto:denis.krv@yandex.ru) (кнопка «Сообщить об ошибке» — в меню «Настройки → Безопасность»). Не присылайте файлы с реальными СНИЛС и ФИО.

## Защита персональных данных

Программа обрабатывает ПДн работников (ФИО, СНИЛС) и рассчитана на ИСПДн УЗ-3.

| Уровень | Технология |
|---------|-----------|
| Хранение | Только локально, `%APPDATA%\NormaOT` (Linux: `~/.local/share/NormaOT`, доступ только владельцу); ФИО и СНИЛС шифруются по полям (Fernet, AES-128-CBC + HMAC) |
| Мастер-ключ | Windows: DPAPI (привязан к пользователю Windows). Linux: связка ключей ОС (Secret Service) или файл, зашифрованный парольной фразой. Дополнительно — необязательная парольная фраза (PBKDF2-HMAC-SHA256, 600 000 итераций) |
| Сеть | Только `edu.rosmintrud.ru`, TLS 1.2+, проверка сертификата по умолчанию |
| XML | Безопасный разбор (defusedxml, лимиты на размер и глубину), проверка по XSD |
| Логи | Фильтр ПДн и секретов (СНИЛС, ФИО, телефоны, ключи, токены) |
| Аудит | Журнал событий безопасности с HMAC-цепочкой, проверка целостности в «Инструменты → Просмотр логов» |
| Сессия | Автоблокировка по таймауту, `Ctrl+L` |
| Временные файлы | Изолированный каталог с доступом только для пользователя, затирание при удалении |

Если парольная фраза потеряна, зашифрованные данные восстановить нельзя.

Подробно: [docs/SECURITY.md](docs/SECURITY.md) · [docs/HARDENING.md](docs/HARDENING.md) · [docs/OPSEC_GUIDE.md](docs/OPSEC_GUIDE.md) · [docs/PRIVACY.md](docs/PRIVACY.md) · [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

### Ограничения

- Программа **не** является сертифицированным СКЗИ, сертификация ФСТЭК/ФСБ не проводилась, ГОСТ-криптография не используется.
- Защищённость данных зависит от защищённости рабочего места (шифрование диска, антивирус, обновления, учётные записи).
- Организационные меры (политика обработки ПДн, приказы, допуск) обязательны и техническими средствами программы не заменяются.

Содержимое репозиториев одинаковое. Архивы сборок в репозиториях не хранятся — только на [сайте](https://normaot.ru/reestr.html). Изменения публикуются сначала в основной репозиторий, затем в зеркало:

```bash
git remote add ru https://gitflic.ru/project/denis-krv/norma_ot_reestr.git
git push ru --all
git push ru --tags
git push origin --all
```

### Запуск из исходников

Требования: Windows 10/11 или Linux (Astra Linux на базе Debian 12 и новее, Альт 11), Python 3.12.

```bash
git clone https://gitflic.ru/project/denis-krv/norma_ot_reestr.git
cd norma_ot_reestr
py -m pip install -r requirements.txt
py main.py
```

Linux (Python 3.12 не системный на целевых ОС — удобно `uv python install 3.12`):

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### Тесты

```bash
py -m pytest tests -q
```

Linux (без экрана): `QT_QPA_PLATFORM=offscreen python -m pytest tests -q -p no:cacheprovider` и сквозные сценарии `python tools/linux/smoke_scenarios.py`.

Тесты используют только вымышленные СНИЛС и ФИО и не трогают реальную папку данных (`tests/conftest.py` подменяет `APPDATA`).

### Сборка

Средства сборки: Python 3.12, PyInstaller (версия — в [requirements.txt](requirements.txt)), спецификации `NormaOT_Reestr.spec` (Windows) и `NormaOT_Reestr_linux.spec` (Linux), скрипты в `tools/`.

Windows:

```bash
py -m PyInstaller NormaOT_Reestr.spec --noconfirm
```

Сборка в папку `dist/NormaOT_Reestr/` (`schema/`, `templates/`, `resources/` — в `_internal/`), версия EXE берётся из `VERSION` в `utils/about_dialog.py`. Подпись — `tools/sign_build.ps1` (до упаковки в zip). Полный порядок выпуска — в [AGENTS.md](AGENTS.md), раздел «EXE Build & Release».

Linux: `tools/linux/build_all.sh` собирает `tar.gz`, `.deb` и `.rpm` (порядок и требования к сборочной машине — в [AGENTS.md](AGENTS.md), раздел «Linux Build & Release»).

```
Excel_to_XML/
├── main.py              # Точка входа, главное окно, меню

├── exporters/           # Генерация XML / XLSX / DOCX
├── journal/             # Журнал отправок, синхронизация с реестром
├── protocol/            # Комиссия, программы обучения
├── network/             # Диагностика сети
├── utils/               # Шифрование, аудит, логи, организации, лицензия, UI
├── schema/              # XSD-схемы Минтруда
├── templates/           # Шаблоны DOCX/XLSX
├── tools/               # Подпись и сборка (в т. ч. tools/linux), генераторы сайта
├── tests/               # Автотесты (pytest)
├── docs/                # Документация
└── Reports/             # Отчёты аудита и соответствия
```

## Поддержать проект

Норма ОТ бесплатна и без рекламы. Раз в день при запуске программа на 10 секунд показывает окно «Поддержите проект».

Добровольная лицензия поддержки на год снимает эти окна:

- **«Организация»** — для юрлица, действует на все организации в программе;
- **«Персональная»** — для частного специалиста.

Код лицензии вводится в окне «О программе» и проверяется без интернета. Приём оплаты пока не открыт — подробности на [normaot.ru](https://normaot.ru/license.html).
