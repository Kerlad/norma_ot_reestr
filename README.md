## 📋 Описание

Десктопное приложение (PySide6) для учёта и контроля обучения сотрудников по охране труда (Постановление №2464). Обеспечивает полный цикл: внесение данных → формирование XML → отправка в реестр Минтруда → получение рег. номеров → формирование протоколов → сводный анализ статусов.

---

## 🚀 Возможности

### Внесение и просмотр данных
- Ручной ввод ФИО, СНИЛС (автоформатирование `XXX-XXX-XXX XX`), должности, программ
- Импорт `.xlsx` / `.xls` / `.xml` с валидацией по XSD-схеме
- Создание шаблона XLSX для заполнения
- Автозаполнение данных УЦ/Заказчика из сохранённых настроек
- Поддержка множественных программ обучения (1–29, кроме 5)
- Редактирование и удаление записей через контекстное меню

### Экспорт и передача данных
- Конвертация в XML по XSD-схеме Минтруда
- Отправка XML на сервер через API `edu.rosmintrud.ru` (multipart/form-data)
- Получение SetId после успешной загрузки
- Запрос регистрационных номеров по SetId или СНИЛС
- Экспорт результатов в XLSX

### Журнал проверки знаний
- Автосохранение истории отправок
- Цветовая индикация: «ожидает» / «получен»
- Фильтрация по ФИО/СНИЛС, SetId, статусу, протоколу, датам
- Автообновление рег. номеров по SetId
- Экспорт отфильтрованных записей в XLSX

### Формирование протоколов
- Заполнение шаблона `Protokol_proverki_znanii_OT.docx`
- Выбор номера из списка или «Все» (пакетная генерация)
- Данные комиссии, автозаполнение из журнала
- Протокол одиночного работника с ручным вводом

### Сводка по сотрудникам
- Справочник с ручным вводом и импортом из XLSX
- Динамические колонки программ (макс. 6, по умолч. 1,2,3,4,18,23)
- Статус сотрудника на уровне всех программ:
  - **Не обучен** (🔴) — есть программа без даты обучения
  - **Просрочено** (🟡) — срок действия > 3 лет
  - **Обучен** (🟢) — все программы в актуальном периоде
- Запрос истории из реестра Минтруда по СНИЛС (с таймаутом 0.5с)
- **Текущая ситуация** — мгновенный отчёт по статусам всех сотрудников
- План обучения на текущий/следующий год с приоритетами (Высокий/Средний/Низкий)
- Экспорт XLSX с фильтрацией

### Дополнительно
- Светлая и тёмная темы (Mica-эффект на Windows 11)
- Транспорт: **Requests** / **WinINET** (автовыбор, fallback при SSL-ошибках)
- Диагностика сети (`network/client.py`)

## 📦 Установка

### Требования
- **Python** 3.12+
- **ОС** Windows 10/11

```bash
git clone https://github.com/Kerlad/Excel_to_XML.git
cd Excel_to_XML
pip install -r requirements.txt
python main.py
```

### Сборка EXE
```bash
py -m PyInstaller ExcelXML-Mintrud.spec
```

Готовый EXE: `dist/ExcelXML-Mintrud/ExcelXML-Mintrud.exe` (~6 МБ)

## 💻 Быстрый старт

| Шаг | Действие | Вкладка |
|:---:|----------|---------|
| 1 | Заполните данные УЦ и Заказчика (ИНН, название) | Внесение данных |
| 2 | Загрузите XLSX/XML или введите данные вручную | Внесение данных |
| 3 | Проверьте данные и нажмите «Конвертировать» | Просмотр данных |
| 4 | Выберите XML и отправьте на сервер (нужен API-ключ) | Передача данных |
| 5 | Получите SetId → запросите рег. номера | Передача данных |
| 6 | Сформируйте протокол проверки знаний (DOCX) | Протокол |

## 🔐 Безопасность

Двухуровневая модель защиты: полевое шифрование Fernet + DPAPI.

Подробнее в [docs/SECURITY.md](docs/SECURITY.md).

## 🔌 API Минтруда

Интеграция с `edu.rosmintrud.ru`:
- `POST /api/set/push` — отправка XML
- `POST /api/GetEducatedPersonXML` — запрос по SetId / СНИЛС

Подробнее в [docs/API_MINTTRUD.md](docs/API_MINTTRUD.md).
