# Система Excel-XML для передачи данных в Минтруд

## Описание
Система предназначена для генерации XML файлов с данными работников, обученных требованиям охраны труда согласно 2464, в целях автоматизации внесения информации о работниках в базу данных Минтруда.

## Структура проекта
```
/workspace/
├── main.py                 # Точка входа приложения
├── core/
│   └── data_model.py       # Модель данных и управление записями
├── ui/
│   └── main_window.py      # Графический интерфейс (PyQt6)
├── utils/
│   ├── excel_handler.py    # Работа с Excel (шаблоны, импорт)
│   ├── xml_converter.py    # Конвертация в XML по XSD схеме
│   ├── mintrud_api.py      # API для взаимодействия с сервером Минтруда
│   └── response_parser.py  # Парсинг ответов от Минтруда
├── schema/                 # Директория для XSD схем
└── data/                   # Директория для данных и конфигурации
```

## Функционал

### Вкладка "Внесение данных"
- Ручной ввод данных о работнике (Фамилия, Имя, Отчество, СНИЛС, Должность, программы обучения и т.д.)
- Ввод данных об Учебном центре и Заказчике
- Загрузка XLSX/XML файлов с данными
- Загрузка XSD схемы
- Создание шаблона Excel файла
- Справка по программам обучения

### Вкладка "Просмотр данных"
- Таблица со всеми загруженными данными
- Редактирование записей
- Удаление записей
- Конвертация данных в XML формат

### Вкладка "Отправка данных"
- Ввод и сохранение API ключа (32 символа)
- Отправка XML файла на сервер Минтруда
- Получение SetId после успешной отправки
- Запрос данных по SetId и экспорт в Excel

## Требования к данным

### Валидация полей:
- **СНИЛС**: 11 цифр
- **ИНН**: 10 или 12 цифр
- **Программы обучения**: числа от 1 до 29, за исключением 5 (формат: "1,2,3")
- **Дата**: формат ЧЧ.ММ.ГГГГ или ЧЧММГГГГ, не больше текущей даты
- **Результат**: "Удовлетворительно" или "Неудовлетворительно"

## API Минтруда

### Отправка XML
- URL: `https://edu.rosmintrud.ru/api/set/push`
- Метод: POST
- Формат: multipart/form-data
- Файлы: request.xml (с ApiKey и NeedSend) + data.olot (архив с XML данными)

### Запрос по SetId
- URL: `https://edu.rosmintrud.ru/api/GetEducatedPersonXML`
- Метод: POST
- Формат: multipart/form-data
- Файл: request.xml (с ApiKey и SetId)

## Примечания
- Приложение поддерживает высокое разрешение экранов (HiDPI)
- Все данные хранятся в памяти до закрытия приложения
- API ключ сохраняется в файле data/config.json (в реальном приложении требуется шифрование)
