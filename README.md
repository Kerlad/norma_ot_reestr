## Описание

Система для генерации XML-файлов с данными работников, обученных требованиям охраны труда (постановление №2464), и отправки данных в информационную систему Минтруда России через API.

### Ключевые особенности

- 📝 **Ручной ввод данных** — внесение информации о работниках через веб-форму
- 📊 **Загрузка из Excel** — массовый импорт данных из файлов `.xlsx`
- ✅ **Валидация по XSD** — проверка соответствия схеме Минтруда
- 🚀 **Отправка на сервер** — загрузка XML напрямую на edu.rosmintrud.ru
- 🔍 **Получение рег. номеров** — запрос регистрационных номеров по SetId или СНИЛС
- 📋 **Журнал проверки знаний** — история всех отправок с отслеживанием статусов
- 📄 **Формирование протокола** — автоматическое заполнение шаблона протокола проверки знаний
- 🔐 **Безопасное хранение** — шифрование API-ключа (AES)
- 🎨 **Современный UI** — веб-интерфейс на HTML/CSS/JS

## Возможности

### Внесение данных
- Ввод данных учебного центра и заказчика (ИНН, название)
- Ручное внесение данных работников с валидацией полей
- Автоформатирование СНИЛС в вид `123-456-789 00`
- Поддержка множественных программ обучения (1–29, кроме 5)
- Создание шаблона XLSX для заполнения

### Просмотр данных
- Таблицы с данными всех работников
- Объединение или замена данных при загрузке новых файлов
- Редактирование и удаление записей
- Конвертация в XML по схеме XSD

### Передача данных
- Ввод и сохранение API-ключа (32 символа)
- Настройки прокси: без прокси / авто (системные) / вручную
- Отправка XML на сервер Минтруда
- Получение SetId после успешной загрузки
- Запрос регистрационных номеров по SetId или СНИЛС

### Журнал проверки знаний
- Автоматическое сохранение истории отправок
- Цветовая индикация статусов: «ожидает» / «получен»
- Поиск и фильтрация по ФИО/СНИЛС, SetId, статусу
- Автоматическое обновление регистрационных номеров по SetId

### Формирование протокола
- Заполнение шаблона Word данными комиссии
- Выбор номера протокола из списка или "Все"
- Данные комиссии: название организации, приказ, председатель, члены комиссии, профсоюз
- Данные сохраняются между сессиями

## Установка

### Требования

- **Go:** 1.21 или выше
- **ОС:** Windows 10/11

### Установка зависимостей

```bash
# Клонирование репозитория
git clone https://github.com/Kerlad/Excel_to_XML-GO.git
cd Excel_to_XML-GO

# Установка зависимостей
go mod tidy

# Запуск в режиме разработки
go run cmd/app/main.go
```

### Зависимости

| Пакет | Версия | Назначение |
|-------|--------|------------|
| Go | ≥1.21 | Язык программирования |
| Wails | ≥2.0 | Фреймворк GUI |
| excelize/v2 | ≥2.8 | Чтение/запись XLSX |
| crypto | stdlib | Шифрование AES |

### Сборка

```bash
# Установка Wails
go install github.com/wailsapp/wails/v2/cmd/wails@latest

# Сборка приложения
wails build
```

Результат появится в папке `build/bin/`.

## Использование

### Запуск приложения

```bash
go run cmd/app/main.go
```

Для GUI откройте http://localhost:8080 в браузере (при использовании встроенного сервера).

### Пошаговая инструкция

#### 1. Начальная настройка
1. Откройте вкладку **«Внесение данных»**
2. Заполните раздел **«Данные УЦ и работодателя»**:
   - ИНН УЦ (10 или 12 цифр)
   - Название УЦ
   - ИНН Заказчика (10 или 12 цифр)
   - Название Заказчика
3. Нажмите **«Сохранить данные»**

#### 2. Загрузка данных

**Вариант А: Ручной ввод**
1. Заполните форму работника:
   - ФИО, должность, СНИЛС
   - Номер программы (1–29, кроме 5)
   - Номер протокола, результат, дата
2. Нажмите **«Сохранить данные»**

**Вариант Б: Импорт из файла**
1. Выберите `.xlsx` файл
2. Нажмите **«Загрузить файл»**

#### 3. Конвертация в XML
1. Перейдите на вкладку **«Просмотр данных»**
2. Проверьте загруженные записи
3. Нажмите **«Конвертировать»**
4. Выберите путь для сохранения XML-файла

#### 4. Отправка в Минтруд
1. Перейдите на вкладку **«Передача данных»**
2. Введите API-ключ (32 символа) из личного кабинета на edu.rosmintrud.ru
3. Нажмите **«Сохранить ключ»**
4. При необходимости настройте прокси
5. Выберите XML-файл и нажмите **«Отправить XML на сервер»**
6. **Запишите полученный SetId**

#### 5. Получение регистрационных номеров
1. Введите SetId и нажми��е **��Запросить номера»**
2. Просмотрите полученные регистрационные номера

#### 6. Формирование протокола
1. Перейдите на вкладку **«Протокол»**
2. Заполните данные комиссии
3. Выберите номер протокола
4. Нажмите **«Сгенерировать протокол»**

> ⚠️ **Важно:** После загрузки данных на сервер необходимо перейти на сайт edu.rosmintrud.ru, открыть загруженный реестр, указать структурное подразделение и подписать документы УКЭП. Без подписи данные не будут переданы в реестр.

## API Минтруда

### Настройка API-ключа

1. Зарегистрируйтесь на [edu.rosmintrud.ru](https://edu.rosmintrud.ru)
2. Перейдите в личный кабинет
3. Сгенерируйте API-ключ (32 символа)
4. Вставьте ключ в приложение

### Безопасность

- API-ключ шифруется алгоритмом **AES** с использованием ключа, производного от имени пользователя системы
- Зашифрованные данные сохраняются в `data/api_key.json`
- Ключ невозможно расшифровать на другом компьютере без совпадения имени пользователя
- **TLS верификация** управляется чекбоксом

### Эндпоинты API

| Endpoint | Метод | Назначение |
|----------|-------|------------|
| `https://edu.rosmintrud.ru/api/set/push` | POST | Отправка XML на сервер |
| `https://edu.rosmintrud.ru/api/GetEducatedPersonXML` | POST | Запрос рег. номеров |
