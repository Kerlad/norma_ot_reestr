## 📋 Описание

Десктопное приложение (PySide6) для учёта и контроля обучения сотрудников по охране труда (Постановление №2464). Обеспечивает полный цикл: внесение данных → формирование XML → отправка в реестр Минтруда → получение рег. номеров → формирование протоколов → сводный анализ статусов.

---

## 🚀 Возможности

### Внесение и просмотр данных
- Ручной ввод ФИО, СНИЛС (автоформатирование `XXX-XXX-XXX XX`), должности, программ
- Импорт `.xlsx` / `.xml` с валидацией по XSD-схеме
- Создание шаблона XLSX для заполнения
- Автозаполнение данных УЦ/Заказчика из сохранённых настроек
- Поддержка множественных программ обучения (1–29, кроме 5)
- Редактирование и удаление записей через контекстное меню

### Экспорт и передача данных
- Конвертация в XML по XSD-схеме Минтруда
- Отправка XML на сервер через API `edu.rosmintrud.ru` (multipart/form-data)
- Отправка XML с электронной подписью (файл `.sig`) в РОЛ через красную кнопку «Отправить XML и ПОДПИСАТЬ»
  - Формируется архив `.olot` (ZIP), содержащий `Data.xml` и файл подписи `.sig`
  - Флаг `<NeedSend>true</NeedSend>` — немедленная передача в РОЛ
  - Ответ содержит элементы: `<SetId>`, `<SendEducatedPerson>`, `<Message>`
  - **Статус:** функционал не тестировался по причине отсутствия файла `.sig`
- Получение SetId после успешной загрузки
- Запрос регистрационных номеров по SetId или СНИЛС
- Экспорт результатов в XLSX

### Журнал проверки знаний
- Автосохранение истории отправок
- Цветовая индикация: «ожидает» / «получен»
- Фильтрация по ФИО/СНИЛС, SetId, статусу, протоколу, датам
- Автообновление рег. номеров по SetId
- Экспорт отфильтрованных записей в XLSX

### Формирование протоколов
- Заполнение шаблона `Protokol_proverki_znanii_OT.docx`
- Три подвкладки: «Данные протокола и организации», «Состав комиссии» (динамический список членов), «Программы обучения» (встроенная таблица)
- Сохранение/загрузка данных комиссии
- Выбор номера из списка с автозаполнением даты из журнала
- Протокол одиночного работника с ручным вводом (генерация на отдельной вкладке)

### Сводка по сотрудникам
- Справочник с ручным вводом и импортом из XLSX
- Динамические колонки программ (макс. 6, по умолч. 1,2,3,4,18,23)
- Статус сотрудника на уровне всех программ:
  - **Не обучен** (🔴) — есть программа без даты обучения
  - **Просрочено** (🟡) — срок действия > 3 лет
  - **Обучен** (🟢) — все программы в актуальном периоде
- Запрос истории из реестра Минтруда по СНИЛС (с таймаутом 0.5с)
- **Текущая ситуация** — мгновенный отчёт по статусам всех сотрудников
- План обучения на текущий/следующий год с приоритетами (Высокий/Средний/Низкий)
- Экспорт XLSX с фильтрацией

### Настройки периода обучения (программы В)
- Чекбокс «Обучение по программам В (№6-29) — 1 раз в 3 года» на вкладке «Сводка по сотрудникам»
- При включённом (по умолчанию): все программы используют 3-летний период обучения
- При выключенном: программы 6-29 используют 1-годовой период (до сентября 2026)
- Влияет на: статусы сотрудников, планы обучения, «Текущую ситуацию», «Отчёт по обученным»
- Модуль `utils/training_rules.py` — для удаления достаточно удалить файл и убрать ссылки

### Производительность и стабильность (v2.1.0)
- **QAbstractTableModel** для виртуализации таблиц (5000+ записей без лагов)
- **MultiColumnFilterProxyModel** — поиск по всем колонкам через model/view (не итерация строк)
- **Пакетные SQL-запросы** — N+1 заменён на один JOIN для загрузки сотрудников и программ
- **SQL-фильтрация** — WHERE на уровне базы для set_id, статуса, дат
- **PRAGMA optimizations** — synchronous=NORMAL, temp_store=MEMORY, 8 MB cache
- **Кэширование Fernet (encrypt)** — синглтон шифра + LRU для ciphertext (plaintext не кэшируется)
- **Фоновые Worker'ы** — QThread для импорта, XML, API, планов
- **LRU-кэши** — ответы API и сводка сотрудников с TTL
- **`--profile`** — флаг для cProfile профилирования
- **Стабильный XLSX импорт:**
  - **Потокобезопасность** — импорт выполняется в отдельном `QThread`, UI не зависает
  - **Стриминг** — `openpyxl read_only=True` без загрузки всего файла в память
  - **Прогресс** — реальный прогресс-бар с количеством обработанных строк
  - **Отмена** — кнопка «Отменить импорт» с корректным завершением потока
  - **Лимиты** — файл (`MAX_XLSX_FILE_SIZE_MB=10`) и строки (`MAX_XLSX_ROWS=100000`) проверяются до и во время импорта
  - **Логирование** — полное логирование этапов импорта с уровнями INFO/WARNING/ERROR

### Логирование и диагностика (v2.2.0)
- **Структурированные логи** — формат `timestamp | thread | level | module | message`, ротация 5×5MB
- **Маскировка sensitive data** — 19 regex-паттернов (пароли, СНИЛС, API-ключи, ФИО, proxy-credentials)
- **Встроенный просмотрщик логов** — `LogViewerDialog`:
  - Чтение через `seek` с конца файла (не загружает весь файл в память)
  - Автообновление каждые 2 сек (QTimer)
  - Фильтр по уровню (DEBUG/INFO/WARNING/ERROR/CRITICAL)
  - Поиск по тексту (регистронезависимый)
  - Цветовая подсветка уровней (QSyntaxHighlighter)
  - Кнопки: очистить логи, открыть папку, сохранить ZIP-архив, копировать
  - Отслеживание скролла — автопрокрутка отключается при ручной прокрутке вверх
- **PassphraseDialog при запуске** — если установлена парольная фраза, при старте отображается модальный диалог с иконкой, названием, версией и пояснением. Поле ввода (Password echo) + кнопка «Разблокировать» (зелёная). При отмене — корректное завершение приложения без traceback. При неверной фразе — повторный ввод с предупреждением.
- **Меню «Справка» → «О программе»** — информация о приложении, уведомление о необходимости парольной фразы, управление безопасностью мастер-ключа, кнопка «Сообщить об ошибке». Показывается автоматически при первом запуске.
- **Сообщить об ошибке** — кнопка в диалоге «О программе»: упаковывает логи в ZIP, открывает диалог описания проблемы, затем создаёт письмо в Outlook (COM) с вложенным архивом. Если Outlook недоступен — открывает `mailto:` с путём к архиву.
- **Поддержать разработчика ❤️** — кнопка в диалогах «О программе» и «Справка». Открывает `DonationDialog` с QR-кодом для перевода по СБП. QR-код встроен в код приложения (base64, не отдельный файл). Диалог показывается не чаще 1 раза в 45 дней. Возможно полное отключение напоминаний через чекбокс «Больше не показывать».
- **Пункт меню** — «Инструменты → Просмотр логов»

### Дополнительно
- Светлая и тёмная темы (Mica-эффект на Windows 11)
- Транспорт: **Requests** / **WinINET** (автовыбор, fallback при SSL-ошибках)
- Диагностика сети (`network/client.py`)

## 🔐 Безопасность

Трёхуровневая модель защиты: полевое шифрование Fernet + DPAPI + опциональная passphrase (PBKDF2, 600k итераций).

- **DPAPI** — мастер-ключ привязан к учётной записи Windows (с дополнительной entropy)
- **Passphrase** — дополнительный слой PBKDF2-защиты поверх DPAPI (опционально)
- **Ротация ключей** — `rotate_master_key()` с транзакционной безопасностью
- **Безопасная память** — расшифрованные значения не кэшируются, живут только в локальных переменных
- **Secure backup** — ZIP с фиксированным паролем (без циклической зависимости от мастер-ключа)

Подробнее в [docs/SECURITY.md](docs/SECURITY.md).

QR-код встроен непосредственно в код приложения (base64). Для замены на свой QR используйте `scripts/encode_qr.py`.
