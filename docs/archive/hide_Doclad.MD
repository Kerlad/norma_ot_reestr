# Доклад: Excel-XML для передачи данных в Минтруд

## Зачем нужен проект

С 1 сентября 2022 года вступило в силу **постановление Правительства РФ № 2464** о порядке обучения требованиям охраны труда. Согласно ему, учебные центры обязаны передавать данные о работниках, прошедших обучение, в информационную систему Минтруда России (edu.rosmintrud.ru).

Проект **Excel-XML** решает эту задачу — автоматизирует процесс:
- подготовки данных работников в формат XML
- валидации по XSD-схеме Минтруда
- отправки на сервер через API
- получения регистрационных номеров
- формирования протоколов проверки знаний

## Что решает проект

| Проблема | Решение |
|----------|---------|
| Ручной ввод данных о работниках | Импорт из Excel/XML, автоформатирование СНИЛС |
| Сложная подготовка XML | Автоматическая конвертация с валидацией по XSD |
| Отправка через личный кабинет | Прямая интеграция через API |
| Отслеживание статусов | Журнал проверки знаний с цветовой индикацией |
| Формирование протоколов | Автозаполнение шаблона Word по данным журнала |
| Безопасное хранение ключей | Шифрование AES/Fernet |

## Как работает система

### Архитектура
```
┌─────────────────────────────────────────────────────────┐
│                    PySide6 GUI                          │
├─────────────┬─────────────┬─────────────┬──────────────┤
│  Внесение   │  Просмотр   │  Передача   │   Протокол    │
│   данных    │   данных    │   данных    │               │
└──────┬──────┴──────┬──────┴──────┬──────┴───────┬──────┘
       │             │             │              │
       ▼             ▼             ▼              ▼
┌─────────────┬─────────────┬─────────────┬──────────────┐
│  Импортеры  │  Экспортеры │   API       │   Журнал     │
│ (XLSX, XML) │ (XML, DOCX) │ Минтруда    │  (JSON/SQL)  │
└─────────────┴─────────────┴─────────────┴──────────────┘
```

### Основные вкладки

1. **Внесение данных** — ввод данных УЦ, заказчика, работников; загрузка из Excel/XML
2. **Просмотр данных** — таблица работников, конвертация в XML
3. **Передача данных** — отправка XML на сервер, запрос регистрационных номеров
4. **Журнал проверки знаний** — история отправок с фильтрацией и статусами
5. **Протокол** — генерация протоколов проверки знаний в Word

### Поток работы

```
Excel/XML → Импорт → Валидация → XML (XSD) → API Минтруд → SetId → Рег. номера
                                    ↓
                              Журнал (JSON)
                                    ↓
                              Протокол (DOCX)
```

### Технологический стек

- **GUI**: PySide6 (Qt)
- **Данные**: openpyxl, xlrd, lxml
- **API**: requests, urllib, pycurl, httpx, wininet (на выбор)
- **Безопасность**: cryptography (AES/Fernet)
- **Экспорт**: python-docx (протоколы), XLSX (отчёты)
