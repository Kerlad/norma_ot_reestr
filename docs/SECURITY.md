# 🔐 Архитектура безопасности (ISPDn)

## Статус: ИСПДн (Информационная система персональных данных)

Настоящее приложение обрабатывает персональные данные (ПДн) работников:
- ФИО (фамилия, имя, отчество)
- СНИЛС
- Должность
- Данные об обучении (даты, протоколы, результаты)

Обработка осуществляется **на основании требований законодательства РФ** (Постановление/Приказ 2464, 152-ФЗ, ПП РФ №1119), а не на основании согласия субъекта ПДн.

## 3. Cryptography Used

### 3.1. Algorithms

| Алгоритм | Назначение | Размер ключа | Режим | Примечание |
|----------|-----------|-------------|-------|------------|
| Fernet (AES-128-CBC) | Полевое шифрование | 128-bit | CBC + HMAC | Библиотека `cryptography` |
| PBKDF2-HMAC-SHA256 | Вывод ключа из passphrase | 256-bit output | 600K итераций | Salt: 32 байта случайных |
| SHA-256 | Поисковый хеш СНИЛС | 256-bit | N/A | Не для безопасности |
| HMAC-SHA256 | Integrity аудит-лога и метаданных ключа | 256-bit | N/A | Тег: первые 12 hex-символов |

### 3.2. Что НЕ шифруется

- Должность (`position`) — хранится в открытом виде в БД (не является ПДн, но рекомендуется шифрование)
- `program_id`, `exam_date`, `protocol`, `result` — не ПДн
- Логи приложения — ПДн маскируются
- Экспортированные XML-файлы — намеренно (направляются в Минтруд в открытом виде)
- Экспортированные XLSX-файлы — без шифрования

### 3.3. Key Derivation Flow

```
Passphrase → PBKDF2-HMAC-SHA256 (600K итераций, 32B salt) → Derived Key
Derived Key → Fernet → Wrapped Master Key
Master Key → Fernet → API key, proxy credentials, field encryption
```

## 4. Secrets Management

### 4.1. Master Key

- **Генерация**: `os.urandom(32)` при первом запуске
- **Хранение**: `master.key`, зашифрован через Windows DPAPI (`CryptProtectData`)
- **Entropy**: `b"Excel_to_XML_MasterKey_v3_secure"` (приложение-специфичная)
- **Метаданные**: `master.key.json` с HMAC-SHA256 integrity tag
- **Версионирование**: поле версии в метаданных, поддерживается ротация
- **Повреждение**: архив в `corrupted_keys/` (форензическая копия без удаления)

### 4.2. API Key (Минтруд)

- Зашифрован Fernet с использованием мастер-ключа
- Хранится в `api_key.json`
- Расшифровывается только при отправке API-запросов
- Кэширование расшифрованного значения **отсутствует**

### 4.3. Proxy Credentials

- Зашифрованы Fernet с использованием мастер-ключа
- Хранятся в `proxy_settings.json`
- Расшифровываются только при построении конфигурации прокси

### 4.4. Passphrase (дополнительный слой)

- PBKDF2-HMAC-SHA256, 600 000 итераций, 32-байтовый случайный salt
- Хранится: `passphrase_wrapped.key` (Fernet-зашифрованный derived key)
- Блокировка: не реализована (TODO: добавить 3 попытки)
- Восстановление: невозможно без passphrase (нет backdoor)

## 6. Secure Deployment

### 6.1. Минимальные требования

- Windows 10/11 Professional (с поддержкой BitLocker)
- BitLocker включён на системном диске
- Microsoft Defender или эквивалентный антивирус (активен + обновлён)
- Windows Update — автоматические обновления
- Учётная запись пользователя с надёжным паролем
- Физический контроль доступа к рабочему месту

### 6.2. Переменная окружения

```powershell
# Установка для всех пользователей
[Environment]::SetEnvironmentVariable("EXCEL_XML_PROD", "1", "Machine")
```

### 6.3. Пост-деплоймент проверки

- [ ] Приложение запускается без предупреждений о plaintext-ключе
- [ ] Passphrase установлен и работает
- [ ] Тест API-ключа проходит (подключение к Минтруд)
- [ ] Логи не содержат ПДн в открытом виде
- [ ] Резервное копирование создаётся успешно
- [ ] Автоблокировка активируется после таймаута
- [ ] TLS verify=True (отсутствует TLS_WARNING в audit.log)

## 7. Third-Party Dependencies

### Security-Critical Dependencies

| Библиотека | Назначение | Мин. версия | Примечание |
|-----------|-----------|-------------|------------|
| `cryptography` | Fernet, PBKDF2, HMAC | >=42.0.0 | Требуется мониторинг CVE |
| `lxml` | XSD-валидация | >=5.1.0 | Используется с secure parser settings |
| `defusedxml` | Защита от XXE | built-in | Используется для всех внешних XML |
| `requests` | HTTP/TLS | — | verify=True по умолчанию |
| `PySide6` | GUI | >=6.5 | Event loop, clipboard access |

### Supply Chain Security

- Зависимости зафиксированы в `requirements.txt` (major.minor.patch)
- Рекомендуется `pip-audit` для сканирования CVE
- Нет предварительно собранных бинарных файлов из непроверенных источников
- EXE-сборки через PyInstaller только из зафиксированных зависимостей
