# Чек-лист проверки на Astra Linux и Альт (L-07)

Для ручной проверки на виртуальных машинах целевых ОС. Автоматическая часть уже прогнана в WSL (раздел 1).
Версии ОС не выбраны (`docs/LINUX_PORT.md`, «Решение O-03»): в разделе 2 запишите фактические, результаты ставьте
в две колонки **A** (Astra) и **Alt**: `✓` пройдено, `✗` не пройдено (с номером заметки), `—` не применимо.

## 10. Известные ограничения, найденные при подготовке

- Шрифт: в WSL (Ubuntu без метрических шрифтов) `Times New Roman` подменяется на DejaVu Serif, вёрстка DOCX может отличаться. В `.deb` указан `Recommends: fonts-liberation2 | fonts-liberation`; для Альт и Astra проверить пакет шрифтов (п. 5.6).
- Пароль архива бэкапа ключа выводится из самого ключа: если `master.key` утрачен полностью, бэкап не открыть (на всех ОС). Это следует решать отдельно (хранение пароля бэкапа вне ключа), в рамках порта не менялось.
- Astra 1.7 (Debian 10) не поддерживается колёсами PySide6 6.12 (`docs/LINUX_PORT.md`, раздел про пакеты).
- Зависимости rpm заданы именами библиотек (сонеймами): на Альт и РЕД ОС проверить, что `apt-get install` / `dnf` их разрешает.
