# Протокол проверки знаний — Спецификация генерации

## Обзор

Система генерирует протокол проверки знаний на основе данных из журнала и шаблона Word.

**Входные данные:** Workers из таблицы "Просмотр данных" или Journal  
**Выходной файл:** `.docx` (Word)

---

## Группировка

### По ФИО
Для совпадающих ФИО  — одна строка в таблице. Проверять СНИЛС - при разных СНИЛС и одинаковых ФИО создаются разные строки в протоколе.

### По номеру протокола
При выборе "all" — создаётся отдельный файл на каждый номер протокола

---

## Генерация объёма проверки знаний (секция B20-B24)

### Алгоритм
```
1. Для каждого работника → взять номера программ
2. Для каждого номера программы → получить данные (часы, название)
3. Сформировать текст: "{часы}-часовой программе обучения №{num} «{название}»"
4. Заполнить секцию программ
5. Для дублирующих ФИО — объединить регистрационные номера через ";"
6. Для каждого следующего работника → новая строка таблицы
```

### Формат программы
```
{длительность}-часовой программе обучения №{номер} «{название}»

Пример:
8-часовой программе обучения №1 «Оказание первой помощи пострадавшим»
```
