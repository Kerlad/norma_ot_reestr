# L-08: документ о совместимости с ОС для реестра (Astra Linux, Альт)

Исследование от **2026-10-24**, только по первоисточникам; вторичные источники помечены. Это не юридическое заключение.
Контекст: п. 5 «м» и п. 11 «и» Правил ПП № 1236, срок для прикладного ПО — 01.06.2027.

## 1. Что требует сам закон (первичный текст)

Источник: текст ПП № 1937 на [alta.ru](https://www.alta.ru/tamdoc/25ps1937/) (читался), [government.ru](http://government.ru/docs/all/162383/) — страница не открылась в этом сеансе.

- Подп. «м» п. 5: ПО «совместимо не менее чем с 2 операционными системами» (одна — для группы лиц правообладателей ПО и ОС или для ПО только в составе ПАК).
- Подп. «и» п. 11: к заявлению прилагаются «документы, подтверждающие соответствие программного обеспечения требованию, установленному подпунктом "м" пункта 5». **Вид документа не определён**: ни сертификат, ни протокол, ни форма.
- П. 2 Правил: «совместимость» = «возможность выполнения программным обеспечением своих функций под управлением операционной системы общего назначения» без нарушения корректной работы технических средств.
- Подп. «ф» п. 4: в реестр вносится «информация о совместимости» с ОС, соответствующими требованиям частей 3.7 и 3.9 ст. 2 закона (о безопасности КИИ).
- Срок: п. 6 ПП № 1937, подп. «в» — прикладное ПО с 01.06.2027.
- **Не найдено в первичных источниках:** перечень «доверенных ОС», процедура их определения, разъяснение Минцифры о приемлемой форме документа. Страница госуслуги ([digital.gov.ru](https://digital.gov.ru/ru/activity/govservices/6/)) в списке документов заявки прямо документ о совместимости с ОС не называет.

**Вывод 1.** Закон не называет вид документа. Реалистичный путь — документ от производителя ОС (сертификат совместимости) плюс протокол испытаний; приемлемость для оператора реестра нужно подтвердить запросом в поддержку реестра **до** оплаты каких-либо работ.

## 2. Astra Linux — программа «Ready for Astra»

Источники (первичные, сайт производителя): [порядок вступления](https://astra.ru/ready-for-astra/become-tech-partner/), [Положение по работе с технологическими партнёрами](https://astra.ru/ready-for-astra/become-tech-partner/polozhenie-po-rabote-s-tekhnologicheskimi-partnerami.php), [документация Ready for Astra](https://docs.astralinux.ru/latest/rfa/).

- Документ: **«Ready for Astra Linux Software Certificate»** (испытания проводит правообладатель ОС, п. 3.2.1.1) или **«Software Self-Certificate»** (испытания проводит партнёр, ОС проверяет данные и протокол, п. 3.2.1.2, 6.2.2). Выдаётся сертификат в электронном виде и скан протокола (п. 6.1.3, 6.2.3). Сертификат даёт право маркировки знаком соответствия.
- Порядок: заявка на сайте (реквизиты ЮЛ/ИП: ОГРН, ИНН, адрес по ЕГРЮЛ), согласие с офертой и Положением, личный кабинет, верификация сотрудником Astra, затем запрос на испытания в кабинете.
- Сроки (рабочие дни, Положение п. 9–10): принятие запроса — 10 (Certificate) или 3 (Self); испытания ПО — 10 (Certificate); проверка данных партнёра — 5 (Self).
- Стоимость: **в Положении не указана**; дополнительные работы — отдельными договорами (п. 6.3.5). Уточнить письменно.
- Срок действия сертификата: **в Положении не указан**. Привязка к версии ОС: номер не привязан, но ПО должно работать с ядрами PAX и Generic (п. 6.3.4).
- **Замкнутая программная среда (ЗПС).** Испытания ПО включают работу в ЗПС; для подписи ПО можно запросить комплект ключей ([документация](https://docs.astralinux.ru/latest/rfa/)). Для нас это значит: бинарь и `.deb` придётся подписывать ключами Astra, иначе в режиме ЗПС он не запустится (проверить на ВМ).
- Редакции: в Положении прямо упомянут только **Special Edition**; Common Edition не упоминается.
- В Положении **нет** упоминаний реестра Минцифры и статуса «доверенная ОС».
- Контакты: 8 (800) 222-07-00, info@astralinux.ru; запросы по совместимости — readyfor@astralinux.ru (указан в новости производителя, не в Положении).

## 3. Альт — служба совместимости «Базальт СПО»

Источник (первичный): [basealt.ru/product-compatibility](https://www.basealt.ru/product-compatibility).

- Документ: **двусторонний сертификат совместимости** (подписывают обе стороны) и **протокол тестирования**, который ведёт партнёр по собственной методике; тестировщики «Базальт СПО» повторяют шаги. Образцы сертификата, титульного листа протокола, соглашения о технологическом партнёрстве и протоколов — на странице (PDF/ODT).
- Порядок: скачать бесплатный образ ОС «Альт» (Одиннадцатая платформа) → добиться совместимости → передать материалы (инструкция по развёртыванию, протокол, дистрибутив или удалённый стенд, тестовые лицензии) → повторная проверка службой → сертификат, запись в таблице совместимости.
- Заявка: форма <https://www.basealt.ru/gost>, телефон +7 (495) 123-47-99 доб. 558; ответ на первичный запрос — стремятся за 48 часов.
- Стоимость: **бесплатно** (сертификация, сопровождение, образы).
- Срок оформления и срок действия сертификата: **не указаны**; процедура продления при новых версиях не описана.
- В сертификате указываются «наименование и версия продукта как в Реестре».
- **Ограничение (существенное для нас):** служба работает «только с коммерческими продуктами с несвободной лицензией» либо с коммерческим ПО на основе СПО, внесённым или вносимым в реестр отечественного ПО. **НормаОТ Реестр распространяется под MIT и лежит на GitHub** — может не подойти под эти условия; уточнять письменно до подготовки материалов.
- Упоминания «доверенных» ОС на странице нет; указано, что «Альт СП» сертифицирована ФСТЭК.

## 5. Рекомендуемый план (не коммитит владельца ни на что)

1. Письменные запросы по пп. 1–3 из таблицы (бесплатно, 1–2 письма). Пока нет ответа на п. 1, **деньги и время на оформление сертификатов не тратить**.
2. Параллельно подготовить материалы, нужные при любом исходе: инструкция по развёртыванию (`.deb` для Astra, `.rpm`/tar.gz для Альт), протокол испытаний по чек-листу L-07, тестовая лицензия/код.
3. Для Astra предпочтительно начать с **Self-Certificate** (быстрее: 3 + 5 рабочих дней), если оператор реестра его принимает.
4. Образы для испытаний: Астра — через личный кабинет партнёра (после верификации), Альт — бесплатный образ на basealt.ru.
5. Заявителю нужны реквизиты юридического лица или ИП (форма Astra): уточнить, на кого оформляются документы.
